# 製造時刻・手入力重量の実装（2026-10-15）

## 使い方

1. AndroidのSmooth PrintにQL-820NWBを設定する。
2. 印刷ページの「初回の準備・接続できないとき」から `gelato-label-v2.lbx` をダウンロードし、ファイルの「共有」でSmooth Printへ登録する。
3. フレーバー・担当者・枚数・ケースを除いた正味重量を入力する。
4. 2000〜2100gなら「基準内」と表示し、発行できる。1999g以下、2101g以上、空欄、小数は発行できない。
5. 発行ボタンを押した時点の製造日時（日本時間、年月日＋時分）を確定し、重量と一緒に印刷する。
6. 成功後は重量欄が空になる。フレーバー・担当者は保持する。右側のラベルは直前の発行内容を表示し、次の入力で更新する。

現在公開中のSitesは旧版のままです。development内の修正は自動では公開されません。GitHub PagesなどのHTTPS公開先で端末内通信・実機印刷を確認してください。

## テンプレート

- ファイル：`apps/label-print/public/assets/labels/gelato-label-v2.lbx`
- サイズ：62×29mm。P-touch Editor 5.4で読み込みと印刷プレビューを確認済み。
- オブジェクト：FLAVOR / MANUFACTURED_AT / WEIGHT / STAFF。
- 日時は印刷依頼時にブラウザが取得してテキストで送る。LBXの印刷時日付オブジェクトは使わず、履歴と同じ値を印字する。
- 時刻は端末の時計に依存する。UTC形式を保存し、表示・印字は日本時間に統一する。
- 再発行は元の製造日時・重量・当時の基準を保持。発行操作時刻と回数は別に更新する。
- 旧LBXは元データとして保持するが、新アプリでは参照しない。v2を共有していなければ、Smooth Printがファイル取得エラーを返す可能性がある。
- テンプレート再生成：Python 3で `python scripts/build-label-template.py`。ライブラリ追加は不要。

## 基準の変更

`apps/label-print/public/config.mjs` の `WEIGHT_RULE` を変更する。

```js
{baseWeightG: 2000, upperTolerancePercent: 5}
```

下限は基準重量、上限は `floor(基準重量 × (100＋許容率) ÷ 100)`。入力は整数g。1ケースは常に1Bとして扱い、重量を2kgで割ってケース数を算出しない。枚数は同じケース内容のラベル部数であり、複数ケースの合計重量は入力しない。

## 保存

共有DBは今回の実装対象外。履歴は従来と同じlocalStorage領域に保存する。製造日時、正味重量g、取得方法manual、基準重量、許容率、判定結果を追加した。CSVにも同じ項目を出力する。

古い履歴は「重量未記録（旧形式）」として表示する。重量のない古い履歴の再発行は入力チェックで止める。自動で2000gを補わない。

## 検証

- P-touch Editorで4項目がラベル内に収まることを確認（`label-preview-p-touch.png`）。
- ブラウザで範囲外の発行抑止・基準内のデモ発行・重量欄のクリア・CSV保存を確認。
